# 大明中枢 · 帝王六部厂卫官制

> 全球顶级黑金设计 · 古代帝王权力中枢 · 六部与东厂西厂 · 可视化官制管理平台

一个以明代中央官制为主题的单文件可视化网页：以「帝王黑金」设计语言呈现皇帝、六部、内阁、厂卫（东厂 / 西厂 / 锦衣卫）的权力中枢结构，支持明暗双主题切换与金色粒子动效。

## ✨ 特性

- 🏛️ **官制可视化** —— 帝王 / 内阁 / 六部 / 厂卫的层级关系一目了然
- 🎨 **帝王黑金设计系统** —— 深色（夜朝）与浅色（日朝）双主题，一键切换
- ✨ **金色粒子画布** —— Canvas 动效背景，配朱印呼吸光效
- 🖋️ **中式字体排印** —— Noto Serif SC / 马善政毛笔体 / 站酷小薇
- 📱 **响应式布局** —— 桌面与移动端均可流畅浏览
- 📦 **零依赖单文件** —— 全部 HTML/CSS/JS 集于一个 `index.html`，无需构建

## 🛠️ 本地运行

无需任何依赖，直接用浏览器打开 `index.html` 即可；或启动任意静态服务器：

```bash
# Python
python -m http.server 8000

# Node
npx serve .
```

然后访问 `http://localhost:8000`。

## 📦 部署到 GitHub Pages

1. 仓库 **Settings → Pages**
2. **Source** 选择 `Deploy from a branch`
3. **Branch** 选择 `main` / 目录选择 `/ (root)` → **Save**
4. 稍候片刻，即可通过上方地址访问
